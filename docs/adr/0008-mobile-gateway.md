# 0008. 手机经移动网关以标准 WireGuard 接入

- 状态：已采纳
- 日期：2026-10-12

## 背景

手机系统只允许通过系统 VPN 接口接入网络，而且同一时间只能运行一个 VPN。很多用户的手机上已经在运行代理类工具。组网后端会从 tailscale 切换到内核 WireGuard，不希望手机端随之改动。

## 决定

- Hub 主机上运行一个**移动网关**（内核 WireGuard 接口），手机只和它建立标准 WireGuard 连接，由网关转发进组网；
- **设备与凭据分离**：一台设备可以有多份凭据（第三方客户端一份、自建 App 一份），各自独立吊销，权限按设备授予；
- 配对：控制台添加设备（passkey 签名）→ 分配地址和密钥 → 导出 WireGuard 二维码或代理工具配置；
- 以后的自建 App：WireGuard 为默认传输，UDP 受限时自动切换到私有传输。

## 理由

- 手机与组网后端解耦，后端切换时手机无需改动；
- 标准协议意味着任何支持 WireGuard 的客户端都能接入，包括带 WireGuard 出站的代理工具，不额外占用 VPN 名额；
- 不必为每个平台开发客户端。

## 放弃的方案

- **手机直接加入 tailscale 网络**：需要专用客户端，后端切换时要更换。
- **只使用私有协议**：必须自研全部客户端；网络正常时 WireGuard 更快、更省电。

## 影响

- 移动网关是 Hub 主机上的一个额外组件；
- 手机之间、手机与节点之间的流量都经过网关，不做点对点直连。
