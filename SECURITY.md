# Security policy

nett is in development (milestone M1); releases are published on the [releases page](https://github.com/gotry-io/nett/releases). Security fixes go into the latest release.

Please do not report security issues in public issues. Use "Report a vulnerability" on this repository's Security tab (GitHub private vulnerability reporting); replies and follow-up happen there.

Please include, where possible: the affected component and version (or commit), steps to reproduce, and the impact.

The trust model — what the Hub, a node and the signing tool can and cannot do — is described in [docs/architecture.md](docs/architecture.md) and [docs/design/auth.md](docs/design/auth.md); release signing is in [ADR 0020](docs/adr/0020-release-signing.md).
