# 安全问题报告 · Security Policy

中文 · [English](#english)

nett 处于设计阶段（P0），还没有发布版本。

发现安全问题时，请不要提交公开的 issue。请在本仓库的 Security 页面点击 "Report a vulnerability"（GitHub 私密漏洞报告）提交，回复和后续处理都在那里进行。

报告中请尽量包含：受影响的组件和版本（或提交），复现步骤，影响范围。

## English

nett is in the design phase (P0) and has no released versions yet.

Please do not report security issues in public issues. Use "Report a vulnerability" on this repository's Security tab (GitHub private vulnerability reporting); replies and follow-up happen there.

Please include, where possible: the affected component and version (or commit), steps to reproduce, and the impact.
